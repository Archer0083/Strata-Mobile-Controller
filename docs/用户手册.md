## 1. 安装

### 获取安装包

从仓库的 [Releases](https://github.com/Archer0083/strata-mobile-controller/releases) 页面
下载 `.apk` 文件，直接安装即可。

> 当前发布的是 **debug 构建**，未做正式签名。Android 首次安装时需要允许
> 「安装未知来源应用」。若系统提示风险，选择继续即可 —— APK 的 SHA256 校验和
> 一并发布在 Release 说明中，可自行核对。

### 自行构建

```bash
git clone https://github.com/Archer0083/strata-mobile-controller.git
cd strata-mobile-controller/app
flutter pub get
flutter build apk --debug
```

产物：`app/build/app/outputs/flutter-apk/app-debug.apk`

### 系统要求

| 项目 | 要求 |
|---|---|
| Android 版本 | 6.0（API 23）及以上 |
| CPU 架构 | ARM64 / ARMv7 / x86_64（debug 包内含三种 ABI） |
| 存储 | 约 200 MB（debug 包含三套 ABI） |
| 权限 | 仅网络访问；**不申请**存储、相机、麦克风权限 |

## 2. 连接引擎

### 2.1 准备主机端

在运行引擎的机器上启动服务，绑定到私有网卡，并设置 API Key：

```bash
strata --host 0.0.0.0 --api-key <your-secret>
```

> **安全提醒**：请确保该端口只在你的私有网络内可达（WireGuard 虚拟网卡或局域网），
> 不要直接暴露到公网。

引擎默认监听 **8080** 端口。

### 2.2 让手机能访问到主机

最简单且最安全的方式是 **WireGuard VPN**，让手机获得一个虚拟 IP（如 `10.9.0.18`），
再在 App 里填这个地址。完整步骤见 [第 3 节](#3-wireguard-配置详解)。

若手机与主机在同一局域网，直接填主机局域网 IP 也可。

### 2.3 在 App 中新建配置

1. 打开 App → **设置** 页（或连接页右上角 `+`）
2. 点击**新增连接配置**
3. 填写：

| 字段 | 说明 |
|---|---|
| 配置名称 | 任意名称，用于区分多台主机，如「家里那台」 |
| 主机地址 | 主机虚拟 IP 或局域网 IP，如 `10.9.0.18` |
| 端口 | 引擎端口，默认 `8080` |
| API Key | 若主机启用了 `--api-key`，填写同一个密钥；否则留空 |

4. 点击**测试连接**
   - 出现 ✅ 绿色提示并显示当前模型名 → 连接成功
   - 出现红色错误提示 → 见 [故障排查表](#13-故障排查表)
5. 点击**保存修改**

配置保存后即成为激活配置，可在**设置 → 连接配置**中点击切换。

## 3. WireGuard 配置详解

本 App 不自带 VPN 能力，WireGuard 由官方 App 承担。两端的配置要点如下。

### 3.1 需要准备的东西

| 端 | 需要什么 |
|---|---|
| 主机 | 已安装 WireGuard；一条已启用的隧道；引擎运行在隧道网段内 |
| 手机 | 官方 WireGuard App；一条对应的 peer 配置 |

### 3.2 主机端

1. 主机上安装 WireGuard 并新建隧道，设定一个虚拟网段，例如 `10.9.0.0/24`
2. 主机本侧的地址假定为 `10.9.0.1`
3. **引擎必须监听在隧道网卡上**（或 `0.0.0.0`），否则手机连不上：

   ```bash
   # 先确认隧道网卡名与地址
   wg show
   # 引擎绑定到 0.0.0.0 即可同时被局域网和隧道访问
   strata --host 0.0.0.0 --api-key <your-secret>
   ```

4. 在主机 WireGuard 的 `[Peer]` 段写入手机端的公钥，并把手机的地址写入 `AllowedIPs`：

   ```ini
   [Peer]
   PublicKey = <手机端公钥>
   AllowedIPs = 10.9.0.18/32
   ```

### 3.3 手机端

1. 手机上安装 WireGuard App
2. 用「从二维码/文件导入」或「从零创建」生成配置，填入：

   ```ini
   [Interface]
   PrivateKey = <手机端私钥>
   Address = 10.9.0.18/32
   DNS = <你信任的 DNS，可省略>

   [Peer]
   PublicKey = <主机端公钥>
   Endpoint = <主机公网地址或DDNS>:51820
   AllowedIPs = 10.9.0.0/24
   PersistentKeepalive = 25
   ```

3. 打开隧道开关

> **关键点**：手机侧的 `AllowedIPs` 必须包含引擎所在网段（`10.9.0.0/24`），
> 主机侧的 `AllowedIPs` 必须包含手机地址（`10.9.0.18/32`）。
> 这两处是最常见的配置错误来源。

### 3.4 验证隧道

在手机上先不要打开本 App，先用系统浏览器或任意工具访问：

```text
http://10.9.0.18:8080/v1/models
```

- 能返回模型列表 JSON → 隧道通了，跳过第 4 步
- 打不开 → 继续排查第 3.5 节

### 3.5 常见错误对照

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 手机能 ping 通但访问不了 8080 | 引擎只监听了 `127.0.0.1` | 改用 `--host 0.0.0.0` 重启引擎 |
| 完全连不上 | `AllowedIPs` 未包含目标地址 | 检查两端 `AllowedIPs` |
| 隧道频繁断开 | 手机 NAT 超时 | 在手机 peer 加 `PersistentKeepalive = 25` |
| 偶尔连上又断 | 主机防火墙未放行隧道网卡 | 检查防火墙规则是否允许 `wg0` |
| 换了网络就失效 | 手机切换了 Wi-Fi/蜂窝，隧道未自动重连 | 手动切换一次隧道开关 |

## 4. 界面总览

App 顶栏共五个主页面，从左到右：

| 位置 | 页面 | 用途 |
|---|---|---|
| ① | **对话** | 与模型流式对话 |
| ② | **监控** | 实时指标与请求日志 |
| ③ | **控制** | 加载/卸载模型、上下文长度 |
| ④ | **关于** | 引擎 / 硬件 / API 详情 |

对话页顶栏左侧的 ☰ 按钮打开**会话抽屉**；`+` 新建会话；顶栏右侧的图标依次为
导入/导出、图片生成、连接状态、设置。

## 5. 对话页

### 5.1 发送消息

在底部输入框输入文字，点击右下角绿色箭头发送。发送过程中该按钮变为停止按钮，可随时中断。

### 5.2 流式输出与思考过程

模型输出分两部分：

- **思考过程**：以 `>` 开头的绿色折叠区块，点击展开可看到完整的 reasoning 轨迹
- **正文**：Markdown 渲染，支持标题、列表、表格、代码块、行内公式等

右下角实时显示 `token 数` 与 `tok/s`。

### 5.3 思考强度

输入框左侧的调节按钮可设置本条消息的思考强度：

| 级别 | 含义 |
|---|---|
| `none` | 不要求思考，直接回答，最快 |
| `low` | 轻量思考 |
| `medium` | 默认 |
| `high` | 深度思考，最慢但通常更准 |

> 引擎对取值有校验，传入非法值会返回 400。`high` 在引擎侧对应 `xhigh` 模板。

### 5.4 发送图片

1. 点击输入框左侧的 `+` → 选择**图片**
2. 从系统相册选图（App 使用系统选择器，不申请存储权限）
3. 缩略图会显示在输入框上方，发送后随消息一起保存

图片会落盘存入 App 私有目录，会话数据库中记录其路径。
**重新打开该会话时图片依然可见**，导出为 `.json` 时也会一并带出。

### 5.5 顶栏按钮

| 图标 | 功能 |
|---|---|
| ☰ | 打开会话抽屉，切换 / 新建会话 |
| ＋ | 新建会话 |
| 导入导出 | 导出当前会话（四格式）或导入会话 |
| 图片 | 进入图像生成页 |
| ⓘ | 查看当前连接状态与引擎信息 |
| ⚙ | 打开设置 |
| ⋮ | 更多：清空当前会话、重新连接等 |

## 6. 监控页

### 6.1 Model state

顶部卡片显示引擎的五种状态之一：

| 状态 | 含义 |
|---|---|
| `Idle` | 空闲，等待请求 |
| `Reading` | 正在读取/处理输入（prefill） |
| `Generating` | 正在生成 token |
| `Queued` | 请求排队中 |
| `Error` | 引擎报错 |

卡片下方显示最近一次请求的摘要（token 数、耗时等）。

### 6.2 指标网格

| 指标 | 说明 |
|---|---|
| GPU load | GPU 利用率 |
| VRAM | 显存占用 / 总量 |
| GPU temp | GPU 温度 |
| Power | 当前功耗 |
| PCIe | 链路规格（如 `Gen4 x16`）与当前吞吐 |
| CPU | CPU 占用率、核心数、线程数 |
| tok/s decode | 解码速度 |
| tok/s prefill | 预填充速度 |
| KV cache | 缓存命中率 |
| Queue | 请求队列长度 |

折线图配色与引擎自带 WebUI 一致：温度用暖色、PCIe 与磁盘用冷色、prefill 用深绿。

### 6.3 Context 卡

环形图展示当前上下文占用，中心显示已用 / 总 token 数，下方三条横条分别表示
prefill、decode 与 KV 缓存的相对占比。

### 6.4 Recent requests

最近请求列表，展示状态、耗时、token 数等，点击 **Show all (N)** 展开完整列表。

### 6.5 刷新

顶栏的 ↻ 按钮手动刷新。页面也会在可见时自动轮询。

> 若监控页加载失败，先确认连接页状态正常，再检查引擎版本是否支持相应端点。

## 7. 控制页

### 7.1 加载 / 卸载模型

顶部卡片显示当前模型与状态：

- **Loaded** → 引擎已加载模型，可点击**卸载模型**
- **Unloaded** → 点击**加载模型**启动加载

卸载过程有明确的进度提示，期间按钮进入禁用态，完成后给出明确反馈。

> 加载 / 卸载会真正改变引擎状态。若主机开启了自动加载，首次请求会自动拉起模型，
> 此时手动加载按钮可能不可用。

### 7.2 已安装模型

调用引擎的 `/models/installed` 列出主机上全部可加载的模型。

若引擎版本不支持该端点（返回 404），页面会明确说明：

> 当前主机版本没有「已安装模型清单」接口（404）。
> 主机上的 Strata 需要升级到支持 `/models/installed` 的版本。

并降级为显示当前服务的模型，**其余功能不受影响**。

### 7.3 上下文长度

设置模型单次可处理的 token 上限（`--max-context`）：

1. 在输入框填入数值，或直接点选预设档位（8K / 16K / 32K / 64K / 128K / 256K）
2. 点击**保存**
3. 页面提示「已写入 N。重启主机后生效。」

> 该配置写入主机运行配置，需要重启主机才生效，App 无法热切换。

### 7.4 引擎属性与 API Key

控制页下方展示引擎属性（模型路径、构建版本、插槽数等）与 API Key 状态。
API Key 只做掩码显示，实际值存于 Android Keystore。

## 11. 导入与导出

### 11.1 导出

**导出当前会话**（对话页 ⋮ 菜单）：

| 格式 | 用途 | 可回导 |
|---|---|---|
| `.md` | Markdown 转写，便于粘贴进笔记 | ❌ |
| `.json` | 结构化数据 | ✅ |
| `.html` | 自包含网页，可直接浏览 | ❌ |
| `.pdf` | 打印/归档，中文排版正确 | ❌ |

**导出全部会话**：设置 → 会话数据 → 导出全部会话，打包为一个 `.json` 文件。

导出后可调用系统分享面板发送，或存入文件管理器 / 网盘。
文件名会依据会话内容与导出时间命名。

> **已知问题**：部分机型的系统分享面板不支持直接分享渲染后的图片，会提示
> 「无法使用直接分享功能」。此时请改用 `.md` 或 `.pdf` 导出后分享文件。

### 11.2 导入

两种入口：

- 对话页 ⋮ 菜单 → 导入会话
- 设置 → 会话数据 → 导入会话

导入时会**自动识别**文件类型：

- 单个会话对象 → 直接识别
- 会话包（含多个会话）→ 直接识别

识别后先弹出**预览对话框**，显示将要导入的会话数、消息数与导出时间，
确认后才写入。支持 `.json` 格式。

## 12. 常见问题 FAQ

**Q：连接测试提示「无法连接到服务器」？**
A：按顺序检查：① 手机 WireGuard 隧道是否已开启；② 引擎是否在运行；
③ 引擎是否绑定到 `0.0.0.0` 而非 `127.0.0.1`；④ 端口是否为 8080；
⑤ 主机防火墙是否放行隧道网卡。

**Q：提示 401 / 鉴权失败？**
A：主机设置了 `--api-key` 时，App 里必须填写相同的密钥。注意首尾不要带多余空格。

**Q：对话一直转圈，没有输出？**
A：长提示词的 prefill 阶段本身就慢，尤其上下文较大时。App 会显示「思考中」。
若长时间无响应，检查引擎日志与 GPU 显存是否足够。

**Q：监控页显示「请求失败」？**
A：部分监控端点依赖较新的引擎版本。老版本引擎可能不支持 `/metrics` 或
`/api/requests`，此时其余页面仍可正常使用。

**Q：已安装模型列表显示 404？**
A：引擎版本不支持 `/models/installed`。升级引擎即可，或忽略该卡片 ——
App 已降级处理，不影响其他功能。

**Q：设置的上下文长度没有立即生效？**
A：这是设计如此。该值写入主机运行配置，需要重启主机。

**Q：导出的会话能导回来吗？**
A：`.json` 可以，`.md` / `.html` / `.pdf` 是单向的展示格式。
`.json` 会带上图片，因此也是最完整的备份格式。

**Q：重新打开会话后图片不见了？**
A：v0.0.10 起图片已落盘持久化。若仍是旧会话，可在 v0.0.8 及更早版本中
发送过的图片未迁移，重新发送即可。

**Q：应用商店有没有上架版本？**
A：暂未上架。当前通过 GitHub Releases 分发 APK。

## 13. 故障排查表

| 症状 | 可能原因 | 排查步骤 |
|---|---|---|
| 连接测试超时 | 隧道未通 / 端口不通 | 手机浏览器访问 `http://<主机IP>:8080/v1/models` |
| 连接测试 401 | API Key 不一致 | 核对主机 `--api-key` 与 App 中的值 |
| 连接测试 404 | 端口填错 | 确认引擎监听端口，默认 8080 |
| 连接成功但对话无响应 | 引擎未加载模型 | 到控制页手动加载，或等待首次请求自动拉起 |
| 对话只显示最后一个字符 | 早期版本的流式覆盖 bug | 升级到 v0.0.3 及以上 |
| 监控页空白 | 引擎版本不支持监控端点 | 检查引擎版本；其余页面不受影响 |
| 「无法使用直接分享功能」 | 厂商分享面板不支持图片直分享 | 改用 `.md` / `.pdf` 分享文件 |
| 已安装模型返回 404 | 引擎缺少 `/models/installed` | 升级引擎；或忽略该卡片 |
| 上下文长度保存后无效 | 需重启主机 | 重启主机上的引擎进程 |
| App 安装被拦截 | 未允许「安装未知来源应用」 | 设置 → 应用 → 特殊权限 → 安装未知应用 |
| APK 安装后闪退 | 架构不匹配或系统版本过低 | 确认 Android ≥ 6.0 与 ABI 匹配 |

## 14. 隐私与安全

### 数据去向

| 数据 | 存储位置 | 是否上云 |
|---|---|---|
| API Key | Android Keystore | ❌ |
| 会话内容 | App 私有 SQLite 数据库 | ❌ |
| 图片附件 | App 私有目录 | ❌ |
| 连接配置 | 共享偏好（仅激活配置 id） | ❌ |

App **不含**任何遥测、统计分析或崩溃上报组件。

### 权限

App 仅声明网络访问权限。图片附件通过系统相册选择器获取，
不申请存储、相机或麦克风权限。

### 建议

- 引擎端口只监听私有网络，不暴露公网
- 使用非平凡的 API Key，设备丢失时及时轮换
- 导出的文件是明文，注意分享范围
- 定期更新 Android 系统安全补丁

完整威胁模型见 [SECURITY.md](../SECURITY.md)。
